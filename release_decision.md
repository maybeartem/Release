# Решение по выпуску DOC-17

## Решение
Остановить выпуск `1.5.0-rc1`.

## Основание
- `R_RESTORE` — `blocked`, доказательство `restore-target-unavailable`, `last_restore_test = not_available_in_packet`.
- `R_PERFORMANCE` — `not_run`, доказательств нет.
- Документация устарела: `max_attachments=5` вместо `3`, неверный совет по тайм-ауту.
- Критические критерии не выполнены. Снижать пороги качества нельзя.

## Минимальные действия для пересмотра
1. Организовать цель восстановления и провести `R_RESTORE`.
   - Владелец: `technical_executor` + `test_owner`.
   - Доказательство: отчёт о восстановлении, проверка RTO/RPO, контрольный набор данных.
2. Провести `R_PERFORMANCE`.
   - Владелец: `test_owner`.
   - Доказательство: протокол измерения p95 и доли успешных операций.
3. Исправить руководство.
   - Владелец: `technical_executor`.
   - Доказательство: `documentation_changes.md` с исправленным фрагментом.
4. Повторная взаимная проверка пакета.
   - Владелец: `acceptance_owner`.
   - Доказательство: `peer_review.md`.

После выполнения этих действий решение можно пересмотреть.
